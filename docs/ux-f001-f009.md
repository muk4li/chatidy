## Technische Entscheidungen

1. Quelle und Anbieter sind unterschiedliche Dimensionen: Codex ist
   `provider=chatgpt` bei `metadata.source=codex`; Datum ist keine
   Klassifizierung. Ohne exportseitige eindeutige Claude-Code-Kennzeichnung
   darf ein Claude-Chat nicht als Claude Code etikettiert werden.
2. Ordner-/Smart-Routen enthalten numerische, stabile interne IDs und keine
   umbenennbaren Namen. Chat-Routen enthalten URL-kodierte Chat-IDs.
3. `/app/...` wird als SPA ausgeliefert, aber im Authentik-Modus vor
   Auslieferung gegen die serverseitige Sitzung geprüft. Die APIs verwenden
   dieselbe Konto-Scope; Tokens und interne Benutzer-IDs gehören nicht in URLs.
4. Multi-ZIP ist eine **Mehrfachauswahl** mit mehreren separaten Jobs,
   kein globaler atomarer Import. Bei Konflikten muss jede Vorschau einzeln
   und bewusst bestätigt werden. Fehler sind pro Datei sichtbar.
5. Suchtext `×` löscht nur den Suchtext. „Alle Chats“ beendet den
   Tagfilter; weitere Quellen-/Datumsfilter können bewusst bestehen bleiben.
